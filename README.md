# 工作台概览 · Workspace Overview

这台机器的项目仓库都是**私有**的；本仓库是它们的**分类目录**，只放说明，不放代码和数据。

## 分类

| 分类 | 里面是什么 | 可见性 |
|---|---|---|
| 电商后台自动化 | ERP 库存 / 售后 / 退款率的定时任务与报表脚本 | 私有 |
| AI 客服系统 | 自研客服 AI：浏览器壳 + 客服引擎 + 知识库 + 质检 | 私有 |
| 机器人集成 | 飞书机器人（多号）+ 微信消息转发 | 私有 |
| 数据大屏服务 | 售后预警大屏 + 退款率数据服务 | 私有 |

| 运维脚本 | 本地服务守护、计划任务、隐藏窗口运行工具 | 私有 |
